Platted Cable

Materials Needed:

  • Yarn (any weight)
  • Knitting needles (size appropriate for yarn)
  • Cable needle (same size as knitting needles)

Starter Rows: (these rows don't repeat.)


  1. Cast on a multiple of 12 stitches + 3

  2. Starter Row 1: *P3, K9, repeat from * to last 3 sts, P3

  3. Starter Row 2: *K3, P9, repeat from * to last 3 sts, K3

Repeating Rows:


  1. Row 1: *P3, slip 3 sts onto cable needle, leave at back, K3, K3 from cable needle, K3, repeat from * to last 3 sts, P3

  2. Row 2: *K3, P9, repeat from * to last 3 sts, K3

  3. Row 3: *P3, K9, repeat from * to last 3 sts, P3

  4. Row 4: *K3, P9, repeat from * to last 3 sts, K3

  5. Row 5: *P3, K3, slip 3 sts onto cable needle, leave at front, K3, K3 from cable needle, repeat from * to last 3 sts, P3

  6. Row 6: *K3, P9, repeat from * to last 3 sts, K3

  7. Row 7: *P3, K9, repeat from * to last 3 sts, P3

  8. Row 8: *K3, P9, repeat from * to last 3 sts, K3

  9. Repeat Rows 1-8 until the piece reaches the desired length.
  10. Cast off.
